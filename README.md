# C++ 面经八股

一份面向 C++ 求职面试复习的中文题库，按主题整理常见知识点，并提供较详细的参考答案与带注释的伪代码示例。

## 内容概览

文档共整理 **555 道题**，涵盖：

- C++ 基础、面向对象、内存管理与现代 C++
- 并发与线程安全、性能优化、编译链接与工程实践
- 操作系统与 Linux、计算机网络、数据库与缓存
- 系统设计与分布式、数据结构与算法
- Qt、OpenCV、音视频与 FFmpeg

适合按章节复习，也可通过 PDF 中的可点击目录跳转。对适合代码说明的题目，文档提供了中文注释伪代码；C++ 标准库名称使用完整的 `std::` 限定。

## 文件

- [Typst 源文件](C%2B%2B%E9%9D%A2%E7%BB%8F%E5%85%AB%E8%82%A1.typ)：可编辑的原稿，包含题目、答案、目录和参考文献。
- [PDF 版本](C%2B%2B%E9%9D%A2%E7%BB%8F%E5%85%AB%E8%82%A1.pdf)：适合阅读和打印。

## 重新生成 PDF

安装 [Typst](https://typst.app/) 后，在项目目录运行：

```sh
typst compile "C++面经八股.typ" "C++面经八股.pdf"
```

文档默认使用 **Noto Sans CJK SC** 字体。若本机没有该字体，可安装后编译，或在 Typst 源文件中替换字体设置。

## 参考资料

文档末尾列出了 C++ 工作草案、Linux 手册、IETF RFC、Qt、OpenCV、FFmpeg 等官方文档及其他技术资料。内容用于学习和面试复习，具体行为与 API 细节请结合目标语言标准、库版本和平台文档核对。
